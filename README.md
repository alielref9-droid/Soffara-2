# صفارة (Soffara) 🏟️⚽

تطبيق شلة الكورة على الأندرويد مبني باستخدام **Kotlin** و **Jetpack Compose**.
حجز ملاعب + تصويت مين جاي + دردشة جماعية + قرعة الفرق + كشف الحساب والمصاريف + ذكريات الماتشات.

## 📱 مميزات التطبيق (Features)

1. **الحجوزات (Match Bookings)**:
   - بطاقات الحجز على شكل تذاكر ملاعب (Match Ticket) بتصميم صفارة المميز.
   - تفاصيل الملعب، العنوان، السعر (ج.م)، العدد المطلوب، والتاريخ والميعاد.
   - تصويت الحضور المباشر: "✅ أنا جاي" و "❌ مش هقدر".
   - عرض قائمة اللاعبين الحاضرين والمعتذرين، وتحديد اكتمال العدد تلقائياً.
   - إضافة وإلغاء الحجوزات للأدمن.

2. **قرعة الفرق (Team Draw 🎲)**:
   - قرعة جاهزة تعتمد على الحاضرين في الحجز ("أنا جاي") أو قرعة مخصصة باختيار يدوي من الشلة.
   - خوارزمية موازنة ذكية للفرق حسب مستوى اللاعبين (على الله، كويس، تنين) لضمان تكافؤ الفريقين (فريق أ وفريق ب).
   - توثيق تاريخ ووقت إجراء القرعة.

3. **كشف حساب ومصاريف الماتش (Statement & Payments 💰)**:
   - حساب تكلفة الملعب والمجموع المدفوع ونصيب كل لاعب.
   - زر سريع "💳 أنا دفعت" للاعب لتسجيل دفعه، وإمكانية تسجيل دفع لأي لاعب آخر.
   - عرض بيانات الدفع والمحافظ الإلكترونية (InstaPay / كاش).

4. **دردشة الشلة (Crew Chat 💬)**:
   - دردشة فورية مع صورة واسم اللاعب ووقت الرسالة.
   - الرد المباشر مع اقتباس الرسالة (Reply with quote preview).
   - تثبيت الرسائل المهمة في شريط علوي (Pinned Banner).
   - مسح وإلغاء تثبيت الرسائل للأدمن.

5. **ذكريات الماتشات (Memories 📸)**:
   - معرض صور للماتشات بتصميم لقطات الكاميرا والبولارويد.
   - توثيق اسم الملعب وتاريخ الماتش.

6. **دليل الشلة (Crew Directory 👥)**:
   - عرض أعضاء الشلة بمراكزهم المفضلة (حارس، مدافع، وسط، مهاجم) ومستواهم.
   - فتح بروفايل العضو مع إمكانية الاتصال المباشر برقم الموبايل أو فتح محادثة واتساب بضغطة واحدة.
   - طرد الأعضاء وحظرهم مع إدارة قائمة المحظورين للأدمن.

7. **الإعدادات واللغات والثيمات (Settings & Themes ⚙️)**:
   - ثيمات متعددة: ثيم الملعب الأخضر (Pitch 🌿)، الليلي (Night 🌙)، النهاري (Day ☀️)، وثيم Blue Lock ⚡.
   - دعم كامل للغتين: العربية (RTL) والإنجليزية (LTR).
   - تسجيل دخول الأدمن بكود المرور (`M3ss!10B@rca`).

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** MVVM (Model-View-ViewModel) + StateFlow
- **Build System:** Gradle (Kotlin DSL), AGP 9.1.1, Java 21, Android SDK 36
